# Synthetic project example

`Project Atlas` is fictional. The files demonstrate the handoff contract among fact-card, screening, diligence, and IC work without containing real deal information.

Validate it from the repository root:

```bash
python3 scripts/validate_project_bundle.py examples/synthetic-project --require-decision
```

Copy this folder outside the repository before adapting it to a live project. Never commit confidential source materials or completed investment work back into this example.
